# Ветка runs — история анализов Prism Analyzer

Эта ветка не содержит скилла и не имеет общей истории с `main`. В ней хранится только история анализов самого Prism Analyzer: файлы циклов и свидетельства поведения. Кто устанавливает скилл из `main`, эту историю не получает.

## Структура

```
prism-runs/prism-analyzer/
├── evidence/                     — свидетельства поведения скилла
│   └── iteration-1-v0.3/         — первые тесты (версия до v0.4.0, в git не сохранена)
└── cycle-<N>-input.md / -scout.md / -matrix.md / -matrix.json   — файлы циклов самоанализа
```

## evidence/iteration-1-v0.3

Три тестовых кейса, каждый со скиллом и без него:
- `incident-alerting-cycle1` — первый цикл на системе дежурств и алертинга;
- `gate-blocks-without-goal` — шлюз должен остановиться без цели;
- `b2b-sales-cycle2` — второй цикл с журналом изменений и прошлой матрицей.

Итог: со скиллом 22/22 проверки, без скилла 6/22 (`benchmark.md`). Все прогоны со скиллом шли в режиме единого контекста: у тестовых субагентов не было инструмента запуска субагентов. `check_matrix.py` — скрипт, которым проверялась арифметика карты рельефа и индексов угрозы.

Эти тесты сделаны на версии до v0.4.0: тогда в скилле ещё не было назначения Prism, Разведчика, оценок в процентах и номеров брешей.
