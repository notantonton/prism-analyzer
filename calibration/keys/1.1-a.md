# Ключ 1.1-a — зона 1.1 Микро-Тополог

**Известная брешь:** циклическая предпосылка на пути восстановления доступа.
- **Элемент:** вход в менеджер паролей требует одноразового кода с корпоративной почты, а пароль от почты хранится только в менеджере и меняется им самим — ночью, с завершением сеансов почты; сеанс менеджера длится 8 часов; пароль от почты сбрасывает только администратор домена.
- **Механизм:** после ночной смены пароля сотрудник утром не может войти ни в почту (пароль в менеджере), ни в менеджер (код приходит на почту). Выручить может только администратор. Единственный администратор — Ирина — попадает в тот же цикл в ночь своей смены пароля, и выручить её некому. После этого доступ теряет каждый, у кого проходит смена, и правила системы выхода не дают.
- **Почему фатально:** выход есть только вне системы (поддержка поставщиков), то есть через вмешательство Арбитра; смена пароля Ирины гарантированно наступает в пределах 90 дней — внутри горизонта.
- **Законы:** 1.1.10 Циклическая предпосылка; допустимо 1.1.5 (тупиковое состояние «нет доступа ни к почте, ни к менеджеру») или 1.1.1 (взаимная блокировка двух ресурсов).

**НАЙДЕНА, если** блок называет зависимость «менеджер ← код с почты» и «почта ← пароль из менеджера» замкнутым циклом, из которого нет выхода на пути входа или восстановления доступа — для администратора или для всех сотрудников.

**Не совпадение:** только «единственный администратор» без цикла; только «нет бумажной копии»; права доступа к папкам; риск взлома менеджера.
