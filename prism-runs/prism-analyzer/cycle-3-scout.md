## Заявленная цель

«Цель Призмы — верный диагноз фатальных брешей: найти их так, чтобы каждую можно было исправить и проверить исправление.» — SKILL.md:18

Таблица Causa Finalis — SKILL.md:20–26:
- Результат: «Каждая фатальная брешь системы найдена, локализована, объяснена механизмом и основанием, оценена в процентах и снабжена условием закрытия, по которому следующий цикл проверит исправление. Брешей нет — честное «УЗЕЛ ЗАЩИЩЁН»» (:22)
- Бенефициар: «Арбитр — куратор системы; исправитель — исполнитель исправлений» (:23)
- Критерий в прогоне: форма («у 100% брешей есть опора в материалах, локализация, механизм, основание и условие закрытия; советов нет») + полнота: «найдены все известные бреши прогона — заложенные посевом в материалы анализируемой системы и известные Арбитру в этой системе из источников вне Prism… результат случая, одинакового для любой системы, в полноту не входит» (:24)
- Критерий между циклами: «Точность… подтверждённые закрытия — доля исправлений, чей вердикт «ЗАКРЫТА» сверен с контрпосевом и не опровергнут повтором того же механизма в изменённых элементах; ошибочные закрытия; пропуски… Показатель без данных — «не определён», а не лучшее значение» (:25)
- Горизонт: «Один прогон; точность и пропуски подтверждаются следующим циклом» (:26)

Над-цель вынесена «за скобки»: «Призма служит этой над-цели, но не отвечает за неё» (:16). Контракт срабатывания — поле description (SKILL.md:3); текст description не менялся с v0.6.0.
