# Как работать с Prism: два сеанса по кругу

```
 ДИАГНОЗ (цикл N)  ──►  ИСПРАВЛЕНИЕ  ──►  ДИАГНОЗ (цикл N+1)  ──►  ...
   новый сеанс           новый сеанс         новый сеанс
   ищет бреши            закрывает бреши     проверяет исправления
                                             и ищет новые
```

Сеансы всегда разные. Кто исправлял, тот сам себя не проверяет.

## Три правила, чтобы не было бардака

1. **Инструмент — всегда `main`.** Prism запускается из `main`, то есть из проверенной версии.
2. **Исправления — в ветке `fix/cycle-N`.** В `main` их вливаете вы, когда диагноз цикла N+1 подтвердит, что бреши закрыты.
3. **Вся история — в ветке `runs`**, папка `prism-runs/prism-analyzer/`:

| Файл | Кто пишет | Что это |
|---|---|---|
| `cycle-N-matrix.md` / `.json` | Диагноз | Матрица отказов: для вас и для ИИ |
| `cycle-N-input.md`, `-scout.md`, `-snapshot.zip` | Диагноз | Служебное: вход, разведка, снимок |
| `cycle-N-summary-human.md` | Диагноз | Простое изложение для человека |
| `cycle-N+1-changelog.md` | Исправление | Журнал: что исправлено. Вы его утверждаете |

## Ваши действия

1. Запустить **ДИАГНОЗ** (шаблон 1) → прочитать `cycle-N-summary-human.md`.
2. Запустить **ИСПРАВЛЕНИЕ** (шаблон 2) → прочитать `cycle-N+1-changelog.md`. Если согласны — поставить «да» в колонке «Утверждено Арбитром» или просто написать «утверждаю» в следующем промпте.
3. Запустить **ДИАГНОЗ** с N+1. Если бреши закрыты — влить `fix/cycle-N` в `main`.

В шаблонах меняется только N.

## Шаблон 1 — ДИАГНОЗ (цикл N)

```
Запусти Prism Analyzer: самоанализ скилла prism-analyzer, цикл N.

ИНСТРУМЕНТ: клон notantonton/prism-analyzer, ветка main. Прочитай SKILL.md клона и действуй как Диспетчер; базовая директория — корень клона. Установленную копию скилла не используй.

ОБЪЕКТ: цикл 1 — ветка main; цикл N>1 — ветка fix/cycle-{N-1}, коммит HEAD.
Снимок — архив cycle-N-snapshot.zip с sha256. Распакуй во временную папку вне клона и вне папок скиллов. Разведчик и векторы читают только её. Объект не загружай инструментом Skill.

ДАННЫЕ АРБИТРА (я — Арбитр; не переспрашивай, недостающее — допущения с пометкой):
- Цель — заявленная в SKILL.md объекта («Назначение Prism — Causa Finalis»), подтверждаю.
- Среда: Claude Code (облако, CLI, десктоп) и claude.ai; модели Claude; режим А — нужен инструмент субагентов.
- Свидетельства: ветка runs, prism-runs/prism-analyzer/evidence/.
- Соседство: скиллы этого сеанса.
- Цикл N>1: прошлые файлы — ветка runs, prism-runs/prism-analyzer/cycle-{N-1}-*; журнал — cycle-N-changelog.md, утверждаю его [правки: ...].

ХРАНЕНИЕ: git worktree ветки runs вне клона. Файлы cycle-N-* — в prism-runs/prism-analyzer/. Закоммить и отправь: git push origin runs. Код скилла не меняй.

ИТОГ: Матрица отказов целиком и пути к файлам. Затем отдельным файлом cycle-N-summary-human.md — то же простым языком: какие проблемы, чем опасны, когда считаются закрытыми, что в порядке. Без советов и без новых выводов. Его тоже закоммить.
```

## Шаблон 2 — ИСПРАВЛЕНИЕ (после цикла N)

```
Ты — исправитель скилла Prism Analyzer. Ты не Prism: анализ не запускай, скилл не загружай.

РЕПОЗИТОРИЙ notantonton/prism-analyzer. Скилл — ветка main. Матрица — ветка runs: prism-runs/prism-analyzer/cycle-N-matrix.md и .json (git fetch origin runs, worktree вне клона).

ЗАДАЧА
1. Закрой все бреши матрицы цикла N по номерам [или: только ...]. «Условие закрытия» — приёмочный тест для всего класса, а не для одного случая. Способ выбираешь сам.
2. Соблюдай раздел «Для исправителя» в SKILL.md: не трогай prism-runs/ и снимки, не оставляй текстов для анализатора.
3. [Дополнительно: ...]
4. Подними версию: «Версия Prism», metadata.version, matrix-schema.md.
5. Изменения — в новую ветку fix/cycle-N от main. Закоммить и отправь. В main не пиши.
6. Черновик журнала — в формате раздела «Журнал изменений» SKILL.md: строка на каждую брешь и «Прочие изменения». Колонку «Утверждено Арбитром» оставь пустой. Сохрани в ветку runs как prism-runs/prism-analyzer/cycle-{N+1}-changelog.md, закоммить и отправь.
7. В конце: ветка, изменённые файлы, путь к журналу, и 3–5 строк простым языком — что сделано.
```
